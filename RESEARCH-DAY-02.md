2. CONCEPTS TO RESEARCH (60 minutes)
=========================================================================
Q1. What is a Java generic type? Why is <T> useful?
A generic type allows a class, interface or method to work with different data types while maintaining type safety. 
 
  Q2. What does Lombok @Builder generate behind the scenes?
Builder creates a builder class for constructing objects. 

  Q3. What is the Builder design pattern? When to use it?
It is used when an object has to many fields, it enables you to write a data next to the field/parameter. 

  Q4. What is LocalDateTime? How is it different from Date?
Is part of the java 8 date and time package, it is easier to use and more immutable 

  Q5. Why does a consistent response format matter to frontend developers?
It makes it more predictable and easier to write various error handling logic. It also makes maintenance easier.   

  Q6. What does @JsonInclude(JsonInclude.Include.NON_NULL) do?
It tells SpringBoot to exclude values that have a null value. 

  Q7. What is a static factory method? Why use Response.success(...) instead of new Response<>()?
A static factory method is a static method that creates and returns an object.
